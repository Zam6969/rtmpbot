# Privacy Policy – DJ Recorder (rtmpbot)

DJ Recorder is a private Discord bot run for one community. It records DJ sets streamed to its own server
and uploads them to that community's YouTube channel.

**What it stores**
- Discord user ID, the username a DJ chooses, their timezone, their video privacy choice, and their stream key.
- Recordings of streams sent to the server. Each recording is deleted from the server as soon as it has been
  uploaded to YouTube.
- An access token for the YouTube channel that an administrator connected. It is used only to upload videos
  to that channel and to show the channel's name to administrators.

**What it does not do**
- It does not sell or share data with anyone, apart from uploading recordings to YouTube as described above.
- It does not access any Google data other than uploading to, and reading the name of, the connected channel.

**Removing your data**
Ask a server administrator to remove your registration. An administrator can revoke the bot's YouTube access
at any time at https://myaccount.google.com/permissions.

Use of information received from Google APIs follows the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.
